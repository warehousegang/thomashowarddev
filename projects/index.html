Sally

I lead development of an LLM-powered healthcare voice agent that combines real-time conversation, tool execution, background analysis, and structured visit briefs.

The solution brings together browser and phone interactions, interruption handling, and consent and verification boundaries. Scenario-based evaluations test conversational behavior, structured outputs, safety rules, and failure handling.

// agent orchestration

Symphony

I architect engineering workflows using Codex and Symphony to coordinate 10 specialized agents across implementation, testing, review, debugging, and remediation.

The architecture gives agents scoped context and tool permissions, with isolated execution, cancellation, cost accounting, and audit trails. Verification gates retain human authority over merges and production changes.

// decision support

Referral Intelligence

I architected a physician referral prediction system and an explainable ranking engine using clinical quality, eligibility, specialty alignment, availability, and historical outcomes.

Current work includes supervised models for 30-day referral completion: feature engineering, classification, leakage prevention, and evaluation through precision, recall, ROC-AUC, and calibration. Uncertainty handling and abstention safeguards define the decision boundaries.

  • Python
  • scikit-learn
  • Explainable ML

// solution_design

I start with the customer workflow and the decisions an AI system needs to support. I map the context, tools, integrations, and outputs it requires, then define how to evaluate its behavior and where human judgment belongs.

I stay involved from solution design through implementation: shaping agent capabilities, building prototypes, reviewing code, and using evaluation results to refine the system.

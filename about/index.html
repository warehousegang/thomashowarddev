// about_me

I design and build applied AI solutions: conversational agents, LLM applications, and workflows that coordinate specialized agents.

Applied AI in real workflows

At Snap, I lead development of Sally, an LLM-powered healthcare voice agent. The work brings together real-time conversation, tool execution, background analysis, and structured visit briefs, with explicit consent and authorization boundaries.

My approach starts with the workflow: what someone needs to accomplish, what context the model needs, which tools it can use, and how we will judge the result. Those decisions shape the architecture, the user experience, and the evaluation criteria.

Agentic solutions architecture

I architect how agents manage context, use tools, produce structured outputs, and coordinate work. My engineering workflows use specialized agents across implementation, testing, review, debugging, and remediation. The Symphony project develops that approach from a local harness toward a shared service with scoped execution and review.

I define where model reasoning can guide a workflow and where deterministic checks or human authorization are required. Tool permissions, execution boundaries, cancellation, cost controls, and audit evidence are part of that design.

Evaluation and decision support

I develop evaluation harnesses and scenario-based tests for conversational behavior, structured outputs, safety rules, and failure handling. My work also includes Amazon Bedrock evaluation workflows, goldset reference datasets, and guardrails.

In healthcare, I've architected Referral Intelligence, a Python assessment service with deterministic specialist ranking, visible evidence gaps, and explicit abstention. Its current implementation uses synthetic scenarios and explicit scoring rules.

Predictive machine learning

I built Fourth Down, an end-to-end, production-inspired NFL predictive ML application. It connects historical and current-season data ingestion, leakage-safe features, frozen logistic-regression forecasts, measured validation, forecast archives, and outcome reconciliation. The application makes its inputs and limitations inspectable, while keeping historical evaluation separate from its prospective record.

My separate Physician Referral Success Predictor has an implemented synthetic data foundation for 30-day completion modeling. It combines reproducible generation, eligibility rules, and temporal validation before model training. These projects extend my applied AI work into predictive modeling and the engineering that makes an experiment trustworthy.

From architecture to delivery

My broader engineering expertise and interests include Kubernetes and Go, alongside distributed systems, cloud infrastructure, and production reliability.

I bring more than a decade of engineering leadership and hands-on software development. At Snap, I led delivery of four production applications in four months. I work with the CEO and Product to translate customer needs into AI capabilities, technical priorities, and release criteria, while staying involved in implementation, debugging, and code review.
